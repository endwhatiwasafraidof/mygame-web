# 🎮 MyGame — Web Interface

Современный, быстрый и адаптивный веб-интерфейс для игрового SAMP-проекта **MyGame** (MyGame Stories & MyGame Legacy). 

Проект разработан с упором на современный игровой минимализм, высокую производительность и плавный UX/UI.

## 🚀 Технологический стек

- **Фреймворк:** [Next.js](https://nextjs.org/) (App Router)
- **Язык:** [TypeScript](https://www.typescriptlang.org/)
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/)
- **Анимации:** [Framer Motion](https://www.framer.com/motion/)
- **Иконки:** [Lucide React](https://lucide.dev/)

## 🎨 Дизайн-система

- **Тема:** Темная (Современный киберспортивный/игровой минимализм).
- **Основной цвет:** Оранжевый (`orange-500` для акцентов и свечений).
- **Фон:** Темно-серый, почти черный (`zinc-900` и `zinc-800`).

## ⚡ Функционал релиза («Обертка»)

- **Главная страница:** Разделенный экран для презентации двух серверов (Stories и Legacy).
- **Модуль загрузки:** Секция для скачивания лаунчера (Windows / Android).
- **Новостной блок:** Лента последних событий и обновлений проекта.
- **Интеграции:** Единый социальный блок (Discord, Telegram, VK, YouTube).

## 🛠️ Запуск проекта локально

Убедитесь, что у вас установлен Node.js (версии 18+).

1. Установите зависимости:
   ```bash
   npm install

2. Запустите сервер для разработки:

   ```bash
npm run dev

3. Откройте http://localhost:3000 в вашем браузере.

📦 Скрипты (NPM Scripts)
- npm run dev — запуск проекта в режиме разработчика (с Hot Reload).
- npm run build — сборка оптимизированной production-версии проекта.
- npm run start — запуск собранной production-версии.
- npm run lint — проверка кода линтером (ESLint).
